# Hotbar Refill

When a stack in your hotbar runs out, BestestTool can refill the slot with the same item from the rest of your inventory.

```
/bestesttool refill
```

`/refill` and `/rf` are aliases. Run it again to turn it off, or pass a state: `/refill on`, `/refill off`. Refill needs the `bestesttool.refill` permission.
