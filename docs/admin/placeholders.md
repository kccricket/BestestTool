# PlaceholderAPI

With [PlaceholderAPI](https://www.spigotmc.org/resources/placeholderapi.6245/) installed (optional), BestestTool registers:

| Placeholder | Value |
|---|---|
| `%bestesttool_btenabled%` | `true` if the player has best-tool switching enabled. |
| `%bestesttool_rfenabled%` | `true` if the player has hotbar refill enabled. |
| `%bestesttool_hotbaronly%` | `true` if the player is in hotbar-only mode. |
| `%bestesttool_favoriteslot%` | The player's favorite slot number. |
